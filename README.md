# Komentář k vyhlášce č. 270/2010 Sb., o inventarizaci majetku a závazků

Otevřený komentář k vyhlášce o inventarizaci majetku a závazků — § po §: doslovné znění, výklad, zmocnění a jeho meze, kazuistika, protiargumenty a praktický závěr; inventarizační činnosti a komise, plán inventur, fyzická a dokladová inventura, inventurní soupisy, inventarizační identifikátor, průběžná inventarizace, inventarizace vybraného majetku

Konsolidované znění: dokument e-Sbírky `SB-2010-00270_2018-01-01`.
